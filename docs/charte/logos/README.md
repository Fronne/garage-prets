# Logos

- `cms-icone.svg` — L'icône de l'appli : voiture blanche sur carré bleu nuit, coins à 22 %. Pour l'écran d'accueil, les réseaux, un tampon.
- `cms-voiture.svg` — La voiture seule, en bleu nuit, pour les fonds clairs.
- `cms-voiture-blanche.svg` — La voiture seule, en blanc, pour les fonds bleu nuit ou les photos sombres.

Ce sont les dessins exacts de l'appli (scripts/gen-icons.mjs). On les recopie, on ne les redessine pas.
